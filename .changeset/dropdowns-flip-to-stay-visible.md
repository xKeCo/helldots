Dropdowns now open upward when there is no room below them, instead of being clipped. The ⋯ menu on a thread reply extended past the bottom edge of the thread's scroll container, so reading it meant scrolling the thread first. The measurement is shared by every dropdown in the widget — the status, type and priority pickers, both ⋯ menus and the inbox filter — and is redone on each open. A menu that fits in neither direction still opens downward.
